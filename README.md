# 🚀 منصة "لا تقلق" للعمل الحر (La-Taqlaq Freelance Platform)

منصة عمل حر عربية متكاملة مبنية بمعمارية **MVC المخصصة (Custom MVC)** باستخدام لغة PHP، مصممة لربط العملاء بالمستقلين المحترفين في بيئة عمل آمنة، موثوقة، وذات واجهة مستخدم عصرية (SaaS UI).

---

## ✨ نظرة عامة على المشروع
تأتي منصة "لا تقلق" لحل أكبر مشكلة تواجه أطراف العمل الحر: **"الثقة المتبادلة"**. 
توفر المنصة نظام خزنة مالية آمنة (Escrow System) يحفظ أموال العميل، ويضمن حق المستقل، بالإضافة إلى نظام تحكيم إداري صارم للنزاعات، ومساحات عمل مشتركة للتواصل الفوري ومشاركة الملفات.

---

## 🛠️ المميزات التقنية (Key Features)

* **نظام الخزنة الآمنة (Escrow System):** حجز الأموال تلقائياً عند التعاقد وإطلاقها للمستقل فقط بعد استلام العميل للمشروع والموافقة عليه.
* **مساحة عمل مشتركة (Workspace):** غرف محادثة مخصصة لكل مشروع تدعم التحديث الحي للرسائل النصية (Ajax Polling) ومشاركة ملفات (PDF) بأمان تام.
* **إدارة النزاعات (Dispute Resolution):** لوحة تحكم متقدمة للإدارة للتدخل في حال وجود خلاف، مع صلاحيات مراجعة سجلات المحادثة واتخاذ قرار مالي نهائي (إعادة المال أو صرفه).
* **واجهة مستخدم عصرية (SaaS UI/UX):** تصميم متجاوب (Responsive) مريح للعين، يعتمد على البطاقات الناعمة، الألوان الفاتحة، والتفاعلات الحركية البسيطة لضمان أفضل تجربة للمستخدم.
* **أمان سيبراني عالٍ:** حماية شاملة ضد ثغرات XSS، هجمات SQL Injection، وتأمين المسارات باستخدام نظام توجيه (Router) محمي ومصادقة جلسات (Session Authentication).

---

## 💻 التقنيات المستخدمة (Tech Stack)

* **لغة البرمجة الأساسية:** PHP (OOP)
* **المعمارية:** Custom MVC (Model, View, Controller)
* **قاعدة البيانات:** MySQL / PDO (Prepared Statements)
* **تصميم الواجهات:** HTML5, CSS3, Bootstrap 5
* **التفاعل المباشر:** Vanilla JavaScript, Fetch API / AJAX

---

## 📸 الهيكل الإداري للمنصة (User Roles)
1. **العميل (Client):** ينشر المشاريع، يراجع العروض، يودع الأموال في الخزنة، ويستلم العمل.
2. **المستقل (Freelancer):** يتصفح المشاريع المتاحة، يقدم العروض المالية، وينفذ المهام المطلوبة عبر مساحة العمل.
3. **المدير (Admin):** يمتلك لوحة تحكم شاملة (Dashboard) لمراقبة حركة المنصة، إدارة المستخدمين، حذف المحتوى المخالف، وحسم النزاعات المالية كقاضٍ نهائي.
